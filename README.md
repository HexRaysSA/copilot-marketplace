# Hex-Rays GitHub Copilot CLI Marketplace

GitHub Copilot CLI plugins for the Hex-Rays ecosystem.

## Installation

Add the marketplace to GitHub Copilot CLI:

```bash
copilot plugin marketplace add HexRaysSA/copilot-marketplace
```

## Requirements

- IDA Pro 9.4 or later
- [`uv`](https://docs.astral.sh/uv/)

## [IDA MCP](https://github.com/HexRaysSA/ida-mcp)

The official IDA MCP server for analyzing IDA databases through GitHub Copilot CLI.

```bash
copilot plugin install ida-mcp@HexRaysSA
```

Update an existing installation with:

```bash
copilot plugin update ida-mcp
```
